\doxysubsection{Подробное описание}
Singleton-\/класс для управления TCP-\/соединением и обменом данными с сервером. 

Обеспечивает все виды запросов:\+ регистрацию, авторизацию, восстановление пароля, работу с графиками, управление сессией и т.\+д.
