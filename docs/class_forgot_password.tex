\doxysubsection{Подробное описание}
Класс окна восстановления пароля. 

Реализует трёхшаговый процесс восстановления пароля:\+
\begin{DoxyEnumerate}
\item Ввод логина и запрос кода подтверждения.
\item Ввод кода из email.
\item Ввод нового пароля. 
\end{DoxyEnumerate}
